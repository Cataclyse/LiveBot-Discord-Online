Contenu non transmis par Discord

Le client peut uniquement afficher les données que Discord envoie au bot. Les événements système, stickers, sondages et composants sont affichés séparément.

  1. Ouvre ton application dans le Developer Portal.
  2. Dans Bot → Privileged Gateway Intents, active Message Content Intent. Si Discord exige une approbation pour ton application, elle doit être accordée.
  3. Déconnecte-toi de LiveBot, puis reconnecte-toi avec Lire le contenu des messages coché.
  4. Actualise l’historique du salon.

Si Discord ne fournit toujours pas le contenu, le client ne peut pas le reconstruire.
